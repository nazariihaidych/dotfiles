## Installed plugins
- [i] [mini.statusline](https://github.com/nvim-mini/mini.statusline)
    - a lot better and informative nvim statusline
- [i] [oil.nvim](https://github.com/stevearc/oil.nvim)
    - file navigator
- [i] [vim-sleuth](https://github.com/tpope/vim-sleuth)
    - auto adjustment of 'shiftwidth' and 'expandtab' heuristically based on the current file
    - editorconf - file with defolt config for file indentation style (supportes by nvim defolts)
- [k] [showkeys](https://github.com/nvzone/showkeys)
    - Eye-candy keys screencaster for Neovim
- [i] [treesitter.nvim](https://github.com/nvim-treesitter/nvim-treesitter)
    - key words and other highlighting
- [i] [treesitter-textobjects](https://github.com/nvim-treesitter/nvim-treesitter-textobjects)
    - Syntax aware text-objects, select, move, swap, and peek support
- [i] [which-key](https://github.com/folke/which-key.nvim)
    - WhichKey helps you remember your Neovim keymaps, by showing available keybindings in a popup as you type
- [i] [fzflua](https://github.com/ibhagwan/fzf-lua)
- [i] [project.nvim](https://github.com/ahmedkhalf/project.nvim)
    - provides superior project management
- [i] [LSP](https://github.com/neovim/nvim-lspconfig)
    - lsp config for nvim 
- [i] [dressing.nvim](https://github.com/stevearc/dressing.nvim)
    - dressing defolt input and select windows
- [i] [conform.nvim](https://github.com/stevearc/conform.nvim)
    - formatter plugin
- [i] [blink-cmp](https://github.com/Saghen/blink.cmp)
    - completion plugin with support for LSPs, cmdline, signature help, and snippets
- [i] [csvview.nvim](https://github.com/hat0uma/csvview.nvim)
    - to view csv files, to run use command CsvViewEnable
- [i] [markdown-render.nvim](https://github.com/MeanderingProgrammer/render-markdown.nvim)
    - live markdown rendering
